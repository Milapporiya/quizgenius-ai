## 🌟 Features

- **100% AI & Machine Learning Focus**: Every quiz, MCQ, question bank, and generator output strictly pertains to AI, Machine Learning, Deep Learning, NLP, Computer Vision, and Reinforcement Learning.
- **8 Curated Knowledge Domains**:
  1. *Foundations of AI & Search Algorithms* ($A^*$ Search, Heuristics, Minimax, Alpha-Beta Pruning)
  2. *Supervised Machine Learning & Classifiers* (SVM, Decision Trees, $L_1/L_2$ Regularization)
  3. *Deep Learning & Neural Architectures* (Backpropagation, Activation Functions, Dropout, Adam)
  4. *Natural Language Processing & Transformers* (Self-Attention, BERT, GPT, Tokenization, RLHF)
  5. *Computer Vision & Convolutional Nets* (Max Pooling, ResNet, YOLO, Spatial Convolutions)
  6. *Unsupervised Learning & Clustering* ($K$-Means, PCA Dimensionality Reduction, DBSCAN)
  7. *Reinforcement Learning & Decision Agents* (MDPs, Bellman Equation, $Q$-Learning)
  8. *AI Ethics, Bias & Model Evaluation* (Precision, Recall, $F_1$-Score, Data Leakage, Fairness)
- **AI Quiz Generator**:
  - *Smart Local AI Engine*: Synthesizes domain-aware questions offline without requiring API keys.
  - *Live Gemini AI Integration*: Optional client-side generative AI integration for dynamic questions.
- **Real-Time Assessment Engine**:
  - Countdown timer per question with warning pulses.
  - Question Navigator Matrix (Answered, Marked for Review, Empty, Current).
  - Detailed answer reviews with verified keys and in-depth conceptual explanations.
- **Scholar Leaderboard & Learning Analytics**:
  - Dynamic XP calculation (50 XP per correct question + 100 XP per quiz completion).
  - Live domain mastery bars tracking progress across AI fields.
- **Academic College Viva Q&A Guide**:
  - 8 high-yield conceptual questions & answers prepared for university oral evaluations.
- **Local Persistence & Responsive Design**:
  - Full offline support with HTML5 `localStorage`.
  - Sleek Dark / Light theme toggle with glassmorphism styling.

## 🚀 Quick Start

### 🌐 Live Web App (Deployed)
Launch the application instantly on any device:
👉 **[https://milapporiya.github.io/quizgenius-ai/](https://milapporiya.github.io/quizgenius-ai/)**

### Option 1: Open Directly in Browser
Simply open `index.html` or `quizgenius_ai_app.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Run with Local PowerShell Server
Run the included PowerShell web server:
```powershell
powershell -ExecutionPolicy Bypass -File "server.ps1"
```
Then visit: [http://localhost:8080/](http://localhost:8080/)
